# Classes e Objetos — Java

## O que é
- Classe é o molde; objeto é a instância criada a partir dele.

## Estrutura básica
- Atributos definem o estado do objeto.
- Métodos definem o comportamento.
- O construtor inicializa o objeto com `new`.

## Encapsulamento
- Atributos `private` protegidos por getters e setters.

## Composição
- Uma classe pode ter outra classe como atributo.
